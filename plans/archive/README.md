# G8aural Plans Archive

This folder contains historical planning documents from the g8aural application development process. These documents are preserved for reference but may contain outdated technical details.

## Organization

The archive is organized into three sections:

### 1. Initial Development
These documents represent the earliest planning stages when the application architecture was being determined:

- `2025-12-18-initial-plan.md` - Original project outline with FastAPI + frontend approach
- `2025-12-18-phase-2.md` - Frontend implementation plans for Shiny
- `2025-12-24-single-app.md` - Migration from two-process to single Shiny application
- `2025-12-25-music21.md` - Integration of music21 for improved musical quality

### 2. Feature Implementation
These documents detail specific feature implementations:

- `2026-01-06-ux.md` - UI/UX improvements
- `2026-01-07-multi-grades.md` - Multi-grade difficulty levels (Grades 6-8)
- `2026-01-08-grade-8-compliance.md` - Grade 8 syllabus compliance updates
- `2026-01-09-pitch-detection.md` - Voice singing module implementation
- `2026-01-09-refactor.md` - Refactoring for maintainability
- `2026-01-10-voice-singing-next-steps.md` - Voice singing enhancement plans
- `2026-01-12-singing-grades.md` - Voice singing multi-grade implementation

### 3. Architecture Proposals
These documents contain proposals for future architectural changes:

- `2026-01-22-module-refactoring-plan.md` - Plan for adopting Shiny modules
- `2026-01-22-architecture-recommendations.md` - Options for mobile-optimized architecture

## Status Notes

Many of these documents contain implementation details that are now outdated or have already been incorporated into the codebase. For current architecture and plans, refer to:

- `/plans/VISION.md` - Current application vision and purpose
- `/plans/ARCHITECTURE.md` - Current architecture approach
- `/plans/ROADMAP.md` - Future development plans
